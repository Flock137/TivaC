## (Very rough) documentations on TivaC board 

- `Peripheral-driver-lib.pdf` points out all possible API you can use, along with programming example. The Introduction section is pretty helpful as well. 

-> That document and the data sheet are the most important pieces of manual here. You may neglect the Launchpad and User guide. 

## Programming impression
It's basically API abuse. Not as verbose as the traditional bare-metal C as I initially thought, where you have to, you know, write your own function for the tiniest-tid-bit kinda thing, write the linker script, makefile, fetch your own libs (and it has to be the correct exact version), etc.
